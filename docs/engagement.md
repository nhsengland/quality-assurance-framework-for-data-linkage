## Engagement with the Data Linkage Hub for onboarding onto the Indexing Service

This workflow maps out potential points of DLH engagement or intervention, WHEN:
 
A) A request is made to link two or more data products (where the data is already held within NDIT).

B) A data set is being onboarded to NDIT.

C) Testing and/ or performance monitoring of the data set pipeline indicates a need for corrective action.[^1]
 
[^1]: The performance thresholds and tolerances indicating remedial action is needed require agreement.
